# Arduino IDE setup for FireBeetle-ESP32 (4 MiB flash).
# Copy these properties into boards.local.txt beside the ESP32 package's
# installed boards.txt, then restart Arduino IDE. This repository copy alone
# is not loaded by Arduino IDE. Preserve any unrelated existing overrides.
#
